### 🖼 How the pictures work

You only need **two files** — `index.html` and `styles.css` — and the page will still show every picture. Each image first looks inside an `images/` folder next to the HTML; if the file isn't there, it **automatically swaps to a hosted online copy**, so nothing ever appears broken.

Want your *exact* original photos (your anime avatar and project shots) instead of the placeholders? Create an `images/` folder beside `index.html` and drop in the four files above — they take priority instantly, no code changes needed.

## 🌍 Deploy to GitHub Pages

1. Push this repo to GitHub (files at the **root**, images inside `images/`).
2. Go to **Settings → Pages**.
3. Under *Build and deployment*, choose **Deploy from a branch** → `main` → `/ (root)`.
4. Click **Save** — your site goes live at `https://YOUR-USERNAME.github.io/YOUR-REPO/` in about a minute.

The same files also drop straight onto Netlify, Vercel, Cloudflare Pages or any shared host.
